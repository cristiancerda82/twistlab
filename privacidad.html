Política de Privacidad de Twistlab

Última actualización: 3 de septiembre de 2026

Twistlab no recoge, almacena ni transmite ningún dato personal. No hay cuentas, ni registro, ni anuncios, ni analítica, ni componentes de terceros que observen lo que haces.

La aplicación no pide permisos

La versión para Android no declara ningún permiso del sistema. En particular, no declara el permiso de acceso a Internet, así que el juego es técnicamente incapaz de enviar información a ningún servidor, ni siquiera por error. Funciona entera en modo avión.

Lo que se guarda en tu dispositivo

Para que el juego te resulte útil entre una sesión y la siguiente, Twistlab guarda unos pocos datos en el almacenamiento local del propio dispositivo:

  • La partida en curso, para poder seguir donde lo dejaste.
  • El idioma que hayas elegido.
  • Si tienes el sonido silenciado o no.
  • Tus tiempos y marcas: número de movimientos, mejor tiempo y media.

Esta información no sale del dispositivo. No se envía a nadie, no se comparte y no se copia a ninguna nube. Desaparece por completo cuando desinstalas la aplicación o borras sus datos desde los ajustes de Android.

Versión web

Twistlab también se puede jugar en un navegador, alojado en GitHub Pages. El juego en sí sigue sin recoger nada, pero el servidor que sirve la página es de GitHub y, como cualquier servidor web, registra las peticiones que recibe —dirección IP y datos técnicos del navegador— conforme a la política de privacidad de GitHub. Twistlab no añade ninguna recogida propia por encima de eso, ni tiene acceso a esos registros.

Menores

Twistlab no recoge datos de ninguna persona, y eso incluye a los menores de edad. No hay perfilado, ni publicidad, ni identificadores de seguimiento.

Cambios en esta política

Si alguna versión futura llegase a recoger algún dato, esta página se actualizaría antes de publicar esa versión y la fecha de arriba cambiaría.

Twistlab Privacy Policy

Last updated: 3 September 2026

Twistlab does not collect, store or transmit any personal data. There are no accounts, no sign-up, no ads, no analytics, and no third-party components watching what you do.

The app requests no permissions

The Android version declares no system permissions at all. In particular it does not declare the Internet permission, so the game is technically incapable of sending information to any server, even by mistake. It runs entirely in airplane mode.

What is stored on your device

So that the game is useful between sessions, Twistlab keeps a few things in the device's own local storage:

  • Your game in progress, so you can pick it up where you left off.
  • The language you chose.
  • Whether you muted the sound.
  • Your times and records: move count, best time and average.

This information never leaves the device. It is not sent anywhere, not shared, and not copied to any cloud. It disappears completely when you uninstall the app or clear its data from Android's settings.

Web version

Twistlab can also be played in a browser, hosted on GitHub Pages. The game itself still collects nothing, but the server delivering the page belongs to GitHub and, like any web server, logs the requests it receives — IP address and technical browser details — under GitHub's own privacy policy. Twistlab adds no collection of its own on top of that, and has no access to those logs.

Children

Twistlab collects no data from anyone, children included. There is no profiling, no advertising, and no tracking identifiers.

Changes to this policy

If a future version were ever to collect any data, this page would be updated before that version is published and the date above would change.
